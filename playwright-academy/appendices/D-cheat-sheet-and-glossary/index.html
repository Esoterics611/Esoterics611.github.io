    Appendix D — Cheat Sheet & Glossary¶

    The night-before reference. Skim it; click through to the chapter behind anything that isn't instant.

    D.1 Command cheat sheet¶

    # Environment
uv sync                                   # install deps
uv run playwright install chromium        # install browser
uv run <anything>                         # run a command inside the venv

# Running tests
uv run pytest                             # everything
uv run pytest -m smoke                    # by marker
uv run pytest -m "not slow"               # boolean marker expr
uv run pytest tests/unit -v               # one folder, verbose
uv run pytest path::test_name             # one test
uv run pytest -k "price"                  # name substring
uv run pytest -x                          # stop on first failure
uv run pytest -n 4                        # 4 parallel workers (xdist)
uv run pytest --headed --slowmo 500       # watch it
PWDEBUG=1 uv run pytest path              # Playwright Inspector

# Profiles & reports
PROFILE=ci uv run pytest -m regression    # switch environment
uv run pytest --alluredir=allure-results
uv run allure serve allure-results
uv run playwright show-trace test-results/<...>/trace.zip

# Quality gates
uv run ruff check .                       # lint
uv run black --check .                    # formatting check
uv run black .                            # auto-format
uv run mypy src/                          # type check

    D.2 Locator cheat sheet (priority order)¶

    page.get_by_role("button", name="Search")      # 1. role + accessible name  ← default
page.get_by_label("Maximum Value")             # 2. form fields
page.get_by_text(re.compile(r"^Subtotal"))     # 3. content-anchored
page.get_by_test_id("x-price-primary")         # 4. data-testid when present
page.locator('[data-testid="x"], .x-class')    # 5. CSS, with comma-fallback
page.locator("xpath=//li[contains(@class,'s-item')]//a")   # 6. XPath, last resort

loc.first / loc.nth(2)                          # disambiguate (nth is 0-indexed)
loc.filter(has_text="In stock")                 # filter by content
root.locator(".price")                          # scope within a component root

    D.3 Assertion cheat sheet¶

    # Page state → expect() (RETRIES, waits):
expect(loc).to_be_visible()
expect(loc).to_have_text("...")        / .to_contain_text("...")
expect(loc).to_have_count(5)
expect(loc).to_have_value("shoes")
expect(page).to_have_url(re.compile(r"/sch/"))
expect(loc).not_.to_be_visible()

# In-memory value → plain assert (one-shot):
assert len(urls) > 0
assert subtotal <= budget, "helpful message"

# Error path:
with pytest.raises(ValueError, match="no numeric value"):
    parse_price("garbage")

    D.4 The one-sentence concept list (rehearse aloud)¶

    • POM — classes that hide selectors behind intent-revealing methods; tests speak the domain, not markup. (18)
    • Component object — POM for a reusable region, scoped to a root locator so repeated elements don't collide. (19)
    • Service layer — owns cross-page flows and policy above the page objects; the single home for logic that would otherwise duplicate in tests or bloat a page object. (20)
    • SRP — one reason to change per class: component changes on markup, service on flow, test on assertions. (17)
    • Fixture — dependency injection by parameter name; composes into a graph pytest resolves. (13)
    • Fixture scope — how often it's built (function default → session); wider = faster but less isolated. (13)
    • Data-driven — external YAML → typed dataclasses → pytest_generate_tests; adding a case is a data edit. (14)
    • Auto-waiting — actions wait for actionability; never time.sleep. (7)
    • expect() vs is_visible() — expect retries (waits); is_visible is a non-waiting snapshot. (10)
    • Strict mode — a locator matching >1 element throws instead of guessing. (7)
    • Locator vs ElementHandle — locator is a lazy, re-resolved recipe (no staleness); use it. (7)
    • Browser/context/page — expensive shared browser; cheap isolated context (test boundary); page = tab. (6)
    • Decimal — exact base-10 money, built from a string, never a float. (5)
    • Protocol — structural typing; the paginator depends on a shape, not a class = dependency inversion. (4)
    • Decorator — a function that takes a function and returns a replacement; @d means name = d(name). (A)
    • Test pyramid — many fast unit tests, few slow e2e; unit-testable because logic is extracted into pure functions. (16)
    • Trace viewer — before/after DOM snapshots captured on failure; primary debug tool. (24)
    • XPath — last-resort locator; only for text match and parent/ancestor traversal; never positional. (9)

    D.5 Glossary¶

    Term Meaning
    Actionability the checks (visible, stable, enabled, hittable) Playwright waits for before acting
    Allure a reporting tool that renders test results into an interactive dashboard
    Autouse fixture a fixture applied to every test in scope without being requested
    conftest.py a file whose fixtures/hooks are auto-shared with all tests below it
    Context (BrowserContext) an isolated browser session (own cookies/storage); the test/parallelism boundary
    Dataclass a class with auto-generated constructor/equality/repr from typed fields
    Dependency injection the framework supplies a component's dependencies rather than it constructing them
    Dunder a __double_underscore__ method Python calls implicitly (__init__, __eq__, …)
    Fixture a pytest function that provides a dependency to tests by name
    Flaky passes/fails without code change — usually a timing, ordering, or locator issue
    Headless running the browser with no visible window (CI default)
    Idempotent safe to call repeatedly with the same effect (e.g. cookie_banner.accept())
    Locator a lazy, re-evaluated recipe for finding element(s)
    Marker a @pytest.mark.* tag for selecting/grouping tests
    Parametrize generate one test per data row from one test function
    POM Page Object Model — encapsulate page markup behind intent methods
    Profile a named bundle of environment settings (dev, ci) chosen by PROFILE
    Protocol a structural-typing interface — matched by shape, not inheritance
    Pure function output depends only on input, no side effects → trivially unit-testable
    Service a class owning a business domain's cross-page flows and policy
    SRP Single Responsibility Principle — one reason to change per unit
    Storage state saved cookies + localStorage, reloaded to start tests authenticated
    Strict mode Playwright erroring when a locator matches more than one element
    Trace a recorded timeline (DOM snapshots, network, console) for replay debugging
    uv the Rust-based Python project/venv/dependency manager used here
    xdist the pytest plugin that runs tests across parallel worker processes
